## Rules
1. When implementing the database, follow the rules in ./docs/DATABASE-SCHEMA.md
2. When designing API, follow the rules in ./docs/API-SPECIFICATION.md and ./docs/INTEGRATION-GUIDE.md
3. After implementing a new feature, make sure they can pass the relevant tests in ./tests. If there are additional edge cases that should be tested, write new tests in ./new-tests and test the new feature
4. Everytime before modifying the existing code, read through ./module1-frontend, ./module2-backend, ./module3-face-recognition, ./module4-observability to make sure that your new modification does not conflict with the existing code. If you foresee an unavoidable conflict, ask me before proceeding. If there is no issue, proceed directly.
